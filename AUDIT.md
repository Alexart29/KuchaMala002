# Техническая проверка «Куча-мала» — 22 октября 2026

## Результат
Готовый статический сайт без обязательной сборки. index.html расположен в корне архива; вложенных каталогов нет. Инструкция публикации находится в README.md.

## Подтверждённые изменения
- Из публикуемого комплекта исключены package.json, скрипт сборки, тестовые файлы и устаревшие дубли dist_*. Они не нужны браузеру; их присутствие усложняло выбор публикуемых файлов и могло приводить к ненужному определению проекта как требующего сборки.
- Добавлен netlify.toml: пустая команда сборки, каталог публикации — текущий корень. Добавлен .nojekyll для GitHub Pages.
- В objects.js устранено повторное изменение размера WebGL canvas на каждом кадре: размер и проекция обновляются только при изменении размеров области просмотра.
- В audio.js добавлена попытка возобновления аудиоконтекста при пользовательском взаимодействии из состояния interrupted, встречающегося на iOS.
- В bootstrap.js сообщение о сбое теперь соответствует способу запуска: локальный файл или сайт.
- game.bundle.js обновлён из текущих исходников. Three.js, оригинальные изображения и записи встроены в готовый пакет; внешняя библиотека или сеть для их получения не требуются. Исходные изображения, MP4 и модули также включены отдельно.
- Тексты, персонажи, группы, хороводы и остальные игровые механики не изменялись.

## Ошибка Netlify
Конкретная причина прежнего exit code: 2 НЕ установлена: полного журнала и настроек того развёртывания нет. Существующая команда сборки в доступном окружении выполняется успешно. Удаление ненужных средств сборки устраняет зависимость готового сайта от этого этапа, но не доказывает причину прошлого сбоя. Если прежний проект Netlify продолжает выполнять сборку, проверьте его сохранённые настройки и полный журнал.

## Реально выполнено
- Успешная пересборка пакета игры в рабочем окружении.
- 14 автоматических тестов: последовательность языков, завершение поздравлений и отказ аудио, контроллер 24 находок, запуск групп после каждых трёх, повторное продолжение игры, сальто 1/2/3, карточки, десять фотографий, сохранение счётчика, геометрия сувениров и торта, размещение семьи в кадре для настольных и мобильных пропорций.
- Проверка синтаксиса всех JavaScript-файлов и наличия локальных импортов и ссылок HTML.
- Проверка netlify.toml и отсутствия package.json в готовом комплекте.
- 15 изображений и пять MP4 в пакете побайтно совпадают с отдельными оригиналами. Все пять звуковых дорожек полностью декодированы FFmpeg без ошибок.
- Итоговый ZIP распакован отдельно. Все файлы проверены через настоящий локальный HTTP-сервер по путям / и /repository-name/; ответы 200, содержимое совпадает. Главная страница возвращается по обоим адресам.
- Проверены целостность ZIP, отсутствие вложенных каталогов, наличие index.html в корне.

## Ограничения проверки
Автоматические игровые тесты используют имитацию браузерного окружения. Установленного браузера в среде нет: реальная WebGL-отрисовка, прослушивание звука, производительность и запуск на физическом телефоне НЕ проверены. Наличие относительных путей и работоспособность HTTP проверены, но реальная публикация по HTTPS на GitHub Pages/Netlify НЕ выполнена: аккаунт Netlify и целевой репозиторий не предоставлены. Открытие file:// подготовлено через классический автономный пакет, но браузерный запуск file:// в этой проверке НЕ выполнен. Это подготовленный и автоматически проверенный комплект, а не утверждение о пройденном тестировании во всех браузерах.
