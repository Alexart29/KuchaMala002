# Куча-мала — готовая версия для публикации

Все файлы находятся в корне. Сборка, npm, Node.js, backend и внешние библиотеки не требуются. Three.js и все данные уже включены в game.bundle.js. Все исходные PNG и пять оригинальных MP4 сохранены отдельно и встроены в файл игры. Голоса, рисунки, карточки, группы и анимации сохранены.

## GitHub Pages
1. Распакуйте ZIP. В GitHub нажмите New repository, назовите его kucha-mala и создайте публичный репозиторий.
2. Add file → Upload files: загрузите все распакованные файлы непосредственно в корень, не сам ZIP. Нажмите Commit changes. Проверьте наличие index.html и .nojekyll; если скрытый .nojekyll не загрузился, создайте файл с этим именем через Add file → Create new file.
3. Settings → Pages → Source: Deploy from a branch.
4. Branch: main; папка: /(root); Save.
5. После завершения публикации ссылка появится в Settings → Pages. Адрес проекта: https://ВАШ-ЛОГИН.github.io/kucha-mala/ .

## Netlify Drop
1. Распакуйте ZIP в отдельную папку: index.html должен быть прямо в ней.
2. Откройте https://app.netlify.com/drop и перетащите эту папку в область загрузки.
3. Дождитесь завершения; откройте выданную ссылку сайта.
4. Сборка не нужна. Для существующего проекта, если настройки запрашиваются: Build command — пусто, Publish directory — точка (.), Base directory — корень. Файл netlify.toml уже задаёт отсутствие команды сборки и публикацию корня.
5. При Failed откройте Deploys → неудачный deploy → Deploy log. Нужна первая конкретная ошибка выше итогового exit code. Проверьте, что загружена новая распакованная папка и в ней нет прежнего package.json или папки dist.

## Локальный запуск
Распакуйте весь архив и дважды нажмите index.html (или START_WINDOWS.bat). Файлы не нужно открывать внутри окна ZIP. Звуки разблокируются после первого нажатия в игре. Кнопка звука управляет эффектами и поздравлениями.
